# Démos OFFRO4D

Démos OFFRO4D, jouables dans un terminal. Chaque dossier est autonome : son README dit ce que la démo montre, ce qu'il faut installer et comment la jouer.

| Démo | Ce qu'elle montre | Durée |
|---|---|---|
| [`jev/`](jev/) | Jev, le modèle de jugement rapide : trois types de réponse (oui/non, choix, échelle), un appel combiné, puis sup7 qui s'en sert pour juger les actions d'un agent | 10 à 15 min |
